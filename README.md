# 🗒️ ML.Fraud Detection Model using Machine Learning

This study analyses the ‘creditcard.xlsx’ file and therefore carries out all the necessary 
processes to train ML models with the aim of predicting risky transactions considered 
fraudulent.

## ✨ Features
-Dataset and Data Preparation 🆕<br/> 
-Cleaning Process ✅<br/> 
-Identifying Missing and Duplicates 🔍 <br/> 
-Handling outliers ❌<br/> 
-Feature Engineering 🖥️<br/> 
-Train and test split 📱<br/> 
-Future Scaling 🖥️<br/> 
-Handling class imbalance 🔍 <br/>

## 🧠 Software Used
- Python using Google Collaboratory

## 🧩 Machine Learning Models
- Logistic Regression <br/> 
- Naive Bayes <br/> 
- Random Forest <br/> 
- XGBoost <br/> 

## 🚀 Evaluation of Machine Learning Models
-Precision <br/> 
-Recall <br/> 
-F1-score <br/> 
-AUC <br/> 

## 💡 Lessons Learned
▪ Designed and trained a fraud detection model above 85%  by using Python and Machine learning techniques. 
▪ Built robust framework, pipeline and tooling to support scalable solutions using libraries like Pandas, Numpy, Matplotlib 
and Seaborn. 
▪ Created Tableau dashboards to communicate insights to stakeholders.
